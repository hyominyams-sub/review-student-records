# 생기부 종합일람표 점검 기준

## 기준 문서 우선순위

1. 사용자가 현재 작업에서 명시한 기준
2. 해당 학년도 학교생활기록부 기재요령·길라잡이
3. 학교 내부에서 확정한 기간·용어·표기
4. 국립국어원 표준 표기와 문서 내부 일관성

2026학년도 초등학교 작업에서는 사용자가 제공한 `학교생활기록부 기재요령 주요 개정사항(초등)`과 `학교생활기록부 기재 길라잡이(초등학교)` PDF를 우선 읽는다. 문서가 없거나 학년도가 다르면 사용자가 제공한 최신 안내 문서를 사용하며, 기억에 의존해 규정을 단정하지 않는다.

## 색상 범례

| 색상 | 의미 | 대표 사례 |
|---|---|---|
| 빨강 | 바로 수정해야 할 명확한 오류 | 맞춤법, 실제 이중 띄어쓰기, 온점 누락·오위치, 명백한 조사·어미 오류, 확정 기간 불일치 |
| 주황 | 원자료나 담당자 확인이 필요한 내용 | 문서 기준일 이후 활동, 출처 불명 사실, 부정적·민감한 평가, 예측·단정, 좌표로 표시하기 어려운 전역 문제 |
| 노랑 | 표현·표기 개선 또는 통일 권고 | 용어 통일, 경미한 띄어쓰기, 숫자·인용 표기, 문장 다듬기, 직접 인용 확인 |

정상 문장은 표시하지 않는다. 초록색은 사용자가 모범 사례 표시를 요청할 때만 사용한다.

## 필수 검사 항목

### 맞춤법과 띄어쓰기

- 표준어, 철자, 조사, 어미, 의존 명사, 보조 용언을 확인한다.
- 동일 문장 안의 실제 연속 공백과 단어 좌표상 비정상 간격을 모두 검사한다.
- 표의 열 경계, 양쪽 정렬, 들여쓰기로 생긴 큰 간격은 이중 띄어쓰기로 확정하지 않는다.
- `scan_typography.py` 후보는 렌더링에서 육안 확인한 뒤 빨강으로 확정한다.
- 문서 안에서 같은 개념을 서로 다른 말로 쓴 경우 노랑으로 통일을 권고한다.

### 문장 종결과 `~음.`·`~함.` 표현

- 서술은 기록 문체에 맞는 명사형 종결과 온점을 갖추었는지 본다.
- `~함`, `~음`, `~임` 뒤 온점 누락, 문장 중간의 불완전 종결, 서술형과 명사형의 부자연스러운 혼용을 확인한다.
- 직접 인용, 제목, 항목명, 괄호 안 표기는 기계적으로 명사형으로 바꾸지 않는다.
- 한 문장에 행동·근거·평가가 과도하게 결합된 경우 의미를 바꾸지 않는 범위에서 분리를 권고한다.

### 온점과 문장부호

- 문장 끝 온점 누락, 중복 온점, 단어와 온점 사이 불필요한 공백, 온점 뒤 띄어쓰기 누락을 검사한다.
- `있음 사회:`처럼 다음 교과명·영역명 앞에서 이전 문장 온점이 빠진 경우를 전수 확인한다.
- 날짜의 마지막 온점과 문장 종결 온점을 구분한다.
- 괄호·인용부호와 온점의 위치는 문장의 포함 관계와 안내 문서 예시에 맞춘다.

### 숫자·날짜·기간

- 같은 종류의 수량, 학년, 차시, 순서, 날짜 표기가 문서 안에서 일관적인지 확인한다.
- 날짜는 안내 문서의 `YYYY.MM.DD.` 형식을 우선한다.
- 학급 반장·임원의 시작일은 해당 학년도의 3월 1일(`YYYY.03.01.`)로 검사한다. 시작 연도는 대상 학년도에 맞춘다.
- 기간 문자열 안의 하이픈·괄호·마침표는 해당 학년도 안내 문서와 사용자가 제공한 형식을 따른다. 시작일의 날짜 값 `03.01.` 자체를 오류로 표시하지 않는다.
- 임원 종료일은 학교마다 다르므로 기본값을 두지 않는다. 학교별 학사일정·내부 자료·사용자 지시에서 확인한 날짜만 확정 기준으로 사용한다.
- 종료일 근거가 없으면 날짜를 추정하지 말고 주황색 `학교별 종료일 확인 필요` 항목으로 남긴다.
- 확인된 종료일이 있으면 시작일·종료일·구분 기호·괄호·마침표까지 전체 기간 문자열의 일관성을 비교한다.
- 종합일람표 작성 기준일보다 뒤의 활동일은 주황으로 표시하고 원자료를 확인한다.

### 내용과 기재 적합성

- 관찰 근거 없이 성격·능력·장래를 단정하거나 예측하는 표현을 확인한다.
- 부정적 낙인, 민감정보, 비교·서열화, 과도한 절대 표현은 원자료와 기재 가능 여부를 확인한다.
- 교외 수상·사교육·특정 기관·브랜드·가정환경 등 기재 제한 가능성이 있는 내용은 해당 학년도 지침 근거로 판단한다.
- 직접 인용은 실제 발언인지, 따옴표와 출처가 적절한지 확인한다.
- 활동명·교과명·동아리명·임원 명칭은 공식 명칭과 일치하는지 본다.

### 학생·영역 대응

- 페이지가 바뀌어도 한 학생의 기록을 다음 학생 기록과 섞지 않는다.
- 교과학습발달상황, 창의적 체험활동, 봉사활동, 행동특성 및 종합의견, 출결 등 영역을 구분한다.
- 표 머리글, 페이지 번호, 인쇄 정보는 학생 본문 오류로 집계하지 않는다.

## 기본 제외 항목

- 학생 간 여러 번 반복된 문구·유사 문장 검사는 기본적으로 제외한다.
- 반복 문구 제외는 맞춤법·띄어쓰기·온점·기간·기재 적합성 검사를 제외한다는 뜻이 아니다.
- 사용자가 반복 검사를 명시적으로 요청하면 별도 범주로 추가하고 다른 오류 수와 구분한다.

## 확정 원칙

- 자동 검사 결과는 후보이며 최종 오류는 원문과 렌더링을 확인해 확정한다.
- 확실한 수정과 사실 확인을 색상으로 구분한다.
- 수정 제안은 원문의 교육적 의미와 사실을 바꾸지 않는다.
- 같은 문제를 여러 기준에 중복 집계하지 않고 가장 직접적인 사유 하나로 분류한다.

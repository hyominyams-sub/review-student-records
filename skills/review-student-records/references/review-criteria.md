## 판정과 색상

- 빨강 `error`: 원문과 적용 조건·예외를 확인한 오류. 공식 위반이면 해당 근거를 명시한다.
- 주황 `check`: 사실·학교 규정·출력 범위·학년도 등 확인 필요.
- 노랑 `suggestion`: 표현 개선·통일 제안. ‘확정 오류’와 합산하지 않는다.
- 반복 문구 검사는 기본 제외. 요청 시 유사 문구를 후보로 검토하되, 같은 문장이라는 사실만으로 공식 위반이라 하지 않는다. 도서 중복 입력은 학교급 예외를 확인한다.
- 기존 보라/파랑 이슈 파일은 생성기에서 호환하지만 신규 판정은 위 3색을 사용한다.
- 근거 없는 빨강을 만들지 않는다. 사용자 기준은 추가 점검 조건으로 표시하며 공식 규정과 충돌하면 공식 기준을 바꿔 쓰지 말고 충돌을 설명한다.

## C13 자율동아리

학교계획에 따른 자율동아리는 학년당 1개, 필요시 동아리명·공백을 포함한 소개 30자 이내, 학기초 구성 여부를 확인한다. 정규 동아리 여러 개 활동과 혼동하지 않는다. 초 본문 p.82/PDF88, 중 p.79/PDF85, 고 p.84/PDF90. 출력 자동 표기·줄바꿈과 작성자가 입력한 소개를 구분하여 글자 수를 검토한다.

## C14 체험활동의 주최·주관·승인

창체의 체험활동은 국내 여부와 학교계획·학교 주최/주관을 확인한다. 타 학교 주최/주관은 같은 학교급인지와 학교장 승인을, 교육관련기관은 기관 유형과 학교장 승인을 함께 확인한다. 민간기관 행사에 학교장이 승인했다는 사실만으로 허용하지 않는다. 공동 주최/주관 기관도 모두 허용 범주인지 확인한다. 고등학교는 교육감 승인 학교 밖 교육기관과 학교교육과정 운영계획의 추가 예외가 있다. 주체가 불명확하면 확인 필요로 둔다. 초 본문 p.79/PDF85, 중 p.76/PDF82, 고 p.80/PDF86.

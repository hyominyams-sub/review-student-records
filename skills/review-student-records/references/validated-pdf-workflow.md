# PDF 분석과 출력 검증

기존 초등 종합일람표용 추출기를 유지하면서 다른 학교급·개인별 출력에는 페이지 모드를 제공한다. 표선 자동 추출은 모든 학교급 양식을 자동 해석한다는 보장이 아니다. 현재 문서의 학생·영역 대응은 원본과 대조한다.

## 좌표

- PyMuPDF 단어·도형·주석은 회전 전 좌표다. `page.rect`는 회전 후 좌표이므로 주석 좌표 경계는 `page.rect * page.derotation_matrix`로 확인한다.
- 표 구조 분석에서는 단어와 표선을 모두 `rotation_matrix`로 변환하여 표시 방향의 행·열을 판단한다. 출력 단어의 `bbox`는 원래 네이티브 좌표를 보존한다.
- `pdfplumber` 후보 좌표를 그대로 PyMuPDF 주석에 넣지 않는다. 회전·CropBox·페이지 크기를 확인하고 후보 원문을 PyMuPDF 단어 좌표로 다시 대응시킨다.
- 주석을 넣기 위해 원본 페이지 회전을 제거하거나 본문을 새로 배치하지 않는다.
- 여러 줄은 줄별 `bboxes`를 쓴다. 원문 대응이 불명확하면 `unmarked`로 보고서에 남긴다.

## 종합일람표 구조

`extract_records.py --layout table`은 현재 페이지의 표선에서 머리글 하단·열·행을 찾는다. 기본 번호 열 0, 성명 열 1을 실제 PDF와 대조한다.

- 열별 이름, 학생 수, 첫/마지막 학생, 이어지는 페이지의 같은 학생 여부를 확인한다.
- 표선 누락·열 구조 변경·학생 0명은 경고와 종료 코드 2로 반환한다. 경고를 무시한 전체 점검 완료 판정을 하지 않는다.
- 페이지별 양식이 다른 경우 `--layout pages`의 원문·단어 좌표를 읽고 구간을 따로 매핑한다. 헤더가 다른 페이지를 이전 학생 기록에 임의 연결하지 않는다.
- 개인별 생기부에는 모든 칸의 첫 숫자를 학생 번호로 해석하는 표 모드를 적용하지 않는다.
- 일부 스캔 페이지가 섞이면 텍스트가 있는 페이지가 있다는 이유로 전체 추출 성공을 주장하지 않는다. 모든 페이지의 추출 텍스트와 시각적 본문을 비교한다.

## 표기 후보

- 이중 공백은 산문 열별로 검사한다. `--min-gap auto`와 줄·열의 중앙 간격 비율로 후보를 만들되 양쪽 정렬·들여쓰기·열 경계를 먼저 배제한다.
- 고정 6.8pt 문턱은 작은 글씨의 실제 이중 공백을 놓칠 수 있으므로 기본값으로 쓰지 않는다.
- 온점 후보는 같은 학생·같은 영역 내부인지 확인한다. 다음 학생 시작과 페이지 머리글은 대상이 아니다.
- 명사형 종결 후보는 `니다.` 활용을 포함하되 인용·제목·문서 안내문을 제외한다.
- 공백 제거 텍스트는 문구 검색에만 쓴다. 띄어쓰기 판정에 사용하면 정상인 ‘할 수’가 ‘할수’처럼 보여 오탐한다.

## 검증

1. 유일한 이슈 ID를 사용한다. 표시 항목과 보고서 전용 항목을 구분한다.
2. 모든 표시 항목은 원본 PDF의 지정 페이지에 하나의 Highlight 주석으로 대응한다. 여러 줄도 주석은 한 항목이다.
3. Popup은 별도 메모 창이므로 이슈 건수에 더하지 않는다.
4. 원본/표시본 쪽수·크기·회전·본문 텍스트와 콘텐츠 스트림을 대조한다.
5. 주석의 ID·내용·색상과 보고서의 ID·원본 페이지를 대조한다.
6. 오류/확인 필요/권고를 분리 집계한다. 보고서만 있는 항목도 본문에서 빠뜨리지 않는다.
7. 표시본·보고서 전 페이지를 렌더링한다. 글자 잘림·대체 글리프·겹침·회전·학생 경계·여러 줄 주석을 확인한다.

기계 검증은 PDF의 대응 관계를 확인한다. 사실 판단과 공식 규정 적용은 근거와 원문을 읽어 검토한다.
